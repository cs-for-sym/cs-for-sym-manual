# 第 4 章 核心课程地图：四年要啃下的硬课

打开培养方案，你会被一堆陌生课名砸懵：离散数学、组成原理、编译原理……这一章把它们翻译成”人话”：每门课学什么、为什么非学不可、先修什么，最后拼成一张可回查四年的课程地图。先给结论：CS 本科核心课全国高度趋同——教育部”101 计划”已固化 12 门核心课；它们不是孤立的课，而是一条有严格次序的依赖链，顺序比速度重要。

### 4.1 课程体系全景

#### 4.1.1 101 计划：12 门核心课是全国通用答案

2021 年 12 月，教育部启动计算机领域”101 计划”（本科教育教学改革试点工作计划），由北京大学牵头、33 所高校共建，确定 12 门核心课程，配套 31 本教材和覆盖 110 个模块、650 个知识点的知识图谱（据教育部 2024 年 4 月通报）。无论你在哪所学校，下表就是四年的主战场。

| 课程 | 一句话定位 | 典型修读学期 |
| --- | --- | --- |
| 计算概论（程序设计基础） | 学会用一门语言让计算机听话 | 大一上 |
| 离散数学 | 计算机世界的数学语言：逻辑、图、计数 | 大一 |
| 数据结构 | 组织和存储数据的经典套路 | 大一下—大二上 |
| 算法设计与分析 | 设计”快”的解法并证明它快 | 大二 |
| 计算机系统导论 | 从程序员视角看透整台机器 | 大二 |
| 计算机组成与系统结构 | CPU、指令集、流水线、存储层次 | 大二 |
| 操作系统 | 管理硬件、支撑一切软件的系统软件 | 大二下—大三上 |
| 计算机网络 | 让亿万台机器互相通信的分层协议 | 大三 |
| 编译原理 | 源代码如何变成机器能执行的指令 | 大三 |
| 数据库系统 | 如何可靠地存取海量数据 | 大三 |
| 软件工程 | 从”能跑”到”工业级”的工程方法 | 大二下—大三 |
| 人工智能引论 | 机器学习与智能系统的入门全景 | 大三 |

两点值得大一就记住。其一，12 门课没有一门凑数——它们分别回答”怎么写程序”“机器怎么跑程序”“程序之间怎么协作与交换数据”三层问题；国际知名自学路线 TeachYourselfCS（9 门课）和 OSSU（遵循 ACM/IEEE CS2013 标准的学位级课表）与之高度重合，说明这是全球共识。其二，修读顺序不是教务处的随意安排：数据结构排在算法前、组成原理排在操作系统前，是知识本身的先后逻辑——抢跑后面的硬课只会事倍功半。

#### 4.1.2 课程之间的依赖关系链

按”谁是谁的地基”把课连起来：

[数学地基]
        离散数学 ──────────────┐
        线性代数 + 概率论 ─────┴──→ 机器学习 / 人工智能引论

[软件支柱]
程序设计基础 → 数据结构 → 算法设计与分析 ──→（刷题 / 竞赛 / 各进阶方向）
        │         │
        │         └──────────→ 编译原理
        ▼
[硬件与系统支柱]
数字逻辑 + C → 计算机组成原理 ───────────────→ 编译原理
          （同层：计算机系统导论，与之整合开设、本质相同）
                          │
                          ▼
                       操作系统 ──┬──→ 数据库系统
                                  └──→ 计算机网络 ──→ 分布式系统（进阶）
[应用与工程支柱]
软件工程（贯穿大二大三，依赖程序设计 + 数据结构）

读懂这张图的三个要点：第一，程序设计基础是唯一的总入口，它学得不扎实，后面每门课都会替你还债；第二，系统方向是一条纵深链，组成原理是操作系统、编译原理、网络、数据库的共同地基——卡内基梅隆大学（CMU）的 15-213 课程就被官方定位为”编译器、网络、操作系统、体系结构课程的基础”；第三，数学并非孤岛，离散数学直接喂养算法课，线性代数和概率论则在大三的机器学习课上等你。落到行动只有一条：每学期开学前对着这张图确认”先修补上了吗”，没补就优先补先修，而不是抢跑新课。

### 4.2 软件支柱：从”会写代码”到”会想办法”

程序设计基础（计算概论）——学什么：第一门语言的语法、把大问题拆成小函数的能力、调试与编程风格。国内高校多教 C/C++，斯坦福大学入门课 CS106A 则用 Python 且明确”适合零经验者”——两条路线不冲突：Python 反馈快，C 贴近机器、为系统课打底。为什么重要：一切课程的总入口；写程序的本质不是记语法，而是把模糊需求翻译成精确步骤。先修与时机：无先修，大一上必拿下；暑假若已摸过一门语言，开学后的任务是从”会写”升级到”写得清楚、会调试”。

数据结构——学什么：栈、队列、链表、树、图、哈希表这些经典的数据组织方式，排序与查找，以及复杂度的初步概念（用大 O 记号描述”数据量翻十倍，程序慢多少”）。为什么重要：“程序 = 数据结构 + 算法”是这门学科最经典的概括——真实问题没有现成公式，全靠你判断数据该放进什么容器，判断错了程序就慢到不可用。它也是求职笔试面试的核心考点。先修与时机：先修程序设计，大一下至大二上；每个结构务必亲手实现，只看不写等于没学。

算法设计与分析——学什么：分治、动态规划、贪心、图算法四大套路，以及 NP 完全性（认识”哪些问题理论上没有快速解法”）。为什么重要：CS 自学指南（csdiy.wiki）称它是”计算机科学的核心，几乎一切专业课的基础”。数据结构教你用现成工具，算法课教你造工具：从零设计一个解法并证明它足够快。先修与时机：先修数据结构 + 离散数学，大二；它偏理论易劝退，对策是边学边在力扣（LeetCode）上刷对应专题。

这里还有个”隐形主角”：离散数学学逻辑与证明、集合关系、图论、组合计数；它是算法课的直接先修（MIT 对应课程 6.042 的讲义就叫《Mathematics for Computer Science》），且不需要任何大学先修，是最适合新生提前自学的数学课。

### 4.3 硬件与系统支柱：看透机器之后，代码不再神秘

计算机组成原理 / 体系结构——学什么：指令集（CPU 能听懂的命令）、数据通路、流水线、存储层次与缓存（Cache）。为什么重要：不懂机器模型，上层理解都是脆的——为什么按行遍历二维数组比按列快十倍？为什么递归太深会栈溢出？答案都在这门课。全球标准教材是《深入理解计算机系统》（CSAPP），发源于 CMU 15-213；不少学校把它整合为”计算机系统导论”，本质相同：这门课走 CSAPP 式整机视角（数据的机器表示、处理器、存储层次、链接加载），101 计划将其与组成原理并列为系统类核心，先修程序设计 + 数字逻辑，大二修读。先修与时机：数字逻辑 + C，大二。

操作系统——学什么：进程与线程、虚拟内存（让每个程序”以为”自己独占内存的魔术）、文件系统、并发同步。为什么重要：你写的绝大多数代码都运行在操作系统（OS）之上，不理解它，性能问题和诡异崩溃永远是玄学。经典免费教材是 OSTEP，标杆实验是 MIT 6.S081——在教学用小型操作系统 xv6 上动手术。先修与时机：组成原理 + C，大二下至大三上。

计算机网络——学什么：TCP/IP 分层模型（从网线信号到浏览器网页如何层层接力）、HTTP、拥塞控制。为什么重要：今天的软件几乎都联网，“网”是程序员最高频的排错现场。标准教材是《计算机网络：自顶向下方法》，配 Wireshark 抓包实验，你能亲眼看到自己电脑发出的每个数据包；斯坦福 CS144 更进一步，用 8 个大作业让学生手写一套 TCP/IP 协议栈。先修与时机：操作系统基础，大三。

编译原理——学什么：词法分析、语法分析、中间表示、优化、代码生成——源代码如何一步步变成机器码。为什么重要：学完它，编程语言对你不再是”背下来的规则”而是”被设计出来的系统”，再学任何新语言都快得多，也看得懂编译器报错的真正原因。经典理论教材是《编译原理》（俗称”龙书”）；北大的编译实践课让学生亲手实现一个完整编译器，是国内同类课的标杆。先修与时机：数据结构 + 组成原理，大三，公认的本科”硬课天花板”之一。

### 4.4 应用与工程支柱：把知识变成产品

数据库系统——学什么：关系模型与 SQL（结构化查询语言，操作数据的事实标准）、索引（B+ 树如何让亿级数据毫秒可查）、事务与并发控制（转账不能转一半的原理）。为什么重要：数据是绝大多数重要程序的核心；这门课还是”数据结构 + 操作系统”知识的第一次大汇合，学完会有”原来前两年都在这等着”的通透感。标杆课程是 CMU 15-445（动手写数据库内核 BusTub）和伯克利 CS186。先修与时机：数据结构 + 操作系统，大三。

软件工程——学什么：需求分析、测试、版本管理与团队协作、敏捷开发。为什么重要：它回答一个朴素问题——为什么”能跑的代码”不等于”工业级代码”？一个人写作业可以靠脑子记住细节，十个人维护十万行代码就必须靠工程方法：测试防止改一处坏十处，版本管理（Git）让协作不互相覆盖。它是从”学生作业”走向”真实职场”的桥梁。先修与时机：程序设计 + 数据结构，大二下至大三；务必组队做项目，单刷这门课毫无意义。

人工智能引论与进阶课的位置：人工智能引论由浙江大学吴飞教授牵头建设（101 计划课程之一），内容是搜索、知识表示、机器学习的入门全景，先修线性代数与概率论，通常大三开设——它是”门票”而非”终点”。同样，分布式系统（共识算法、数据复制，标杆课 MIT 6.824）建立在操作系统与网络之上。对新生而言，这些下游课程现在只需知道它们”在地图的什么位置”，等大二的你自己会回来查。

### 4.5 学习方法：动手实现优先

#### 4.5.1 硬课的正确打开方式

12 门硬课有一个共同的”作弊码”：亲手实现一遍。csdiy.wiki 里有句被广泛引用的话：“没有什么能比自己写一个操作系统、一个编译器、一个 TCP 协议栈、一个数据库更能加深理解。”这也是国际名校的共性——MIT 让学生改 xv6、斯坦福让学生手写 TCP/IP、CMU 让学生写数据库内核，顶尖课程无一例外是重实验、大作业（Project-based）的设计。原理很直白：课上听懂只是”认识”，亲手在代码里踩过坑才算”掌握”。落地建议：每学一门系统课就配对应的公开课实验——学操作系统做 MIT 6.S081，学网络做 Stanford CS144，学数据库啃 CMU 15-445 的 BusTub，全部免费公开。关于”动手”的更完整玩法（刷题、竞赛、项目怎么排布），第 5 章专门展开。

#### 4.5.2 自学地图三件套

学校的课未必讲得最好，好在互联网已替你备齐了名师课。三张经过大量学习者验证的”地图”值得收藏：

| 资源 | 定位与特点 | 适合谁 |
| --- | --- | --- |
| TeachYourselfCS | 精选 9 门核心课，每门 100–200 小时；主张”懂底层原理的工程师才有长期竞争力”；时间紧就只读 CSAPP 与 DDIA 两本书 | 目标明确、想抓重点的人 |
| csdiy.wiki（CS 自学指南） | 北大学生发起的完整课程地图，每门课标注先修、难度、学时，收录的全是 MIT/Stanford/CMU/伯克利公开课 | 国内新生首选，中文语境 |
| OSSU Computer Science | GitHub 上 10 万+ 星的学位级完整课表，遵循 ACM/IEEE CS2013 标准，从入门到毕业设计全免费 | 自律性强、想要完整体系的人 |

三者的课程清单与 101 计划高度重合——这反过来印证了 4.1.1 那张表确实就是 CS 教育的”世界标准答案”。使用建议只有两条：一是跟完一门再开下一门，囤课是新手最常见的自我安慰；二是视频看懂不算数，作业做完才算，这与 4.5.1 讲的是同一件事。你现在的任务很简单：把 csdiy.wiki 加进浏览器收藏夹，它会在未来四年反复救你。
