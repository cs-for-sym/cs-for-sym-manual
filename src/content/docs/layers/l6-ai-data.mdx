# L6 智能与数据层

## 7.1 层的定位：从数据中学习的计算范式

传统编程是"人写规则、机器执行"，而智能与数据层开创了另一种范式："机器从数据中学习规则"。这一转变使计算机第一次能够处理那些人类说不清规则的任务——识别人脸、理解语言、预测偏好。以大语言模型（LLM）为代表的深度学习浪潮，更让这一层成为当前整个学科发展最快、影响面最广的一层，其能力正在向其他所有层渗透。

需要注意的是，这一层看似"高高在上"，实则对下层的依赖极深：模型的数学本质是 L1 的概率与优化，训练效率的瓶颈在 L3/L4 的算力与分布式系统，落地形态则是 L5 的软件工程问题。

## 7.2 核心课程与内容

机器学习是地基：监督与无监督学习、泛化与过拟合、特征工程、经典模型（线性模型、决策树、SVM、集成方法）与评估方法。它建立的"偏差—方差""归纳偏置"等概念框架，是理解一切更复杂模型的前提。

深度学习与大模型是本层的引擎：神经网络与反向传播、卷积与注意力机制、Transformer 架构、预训练与微调、提示工程与对齐技术。大模型应用开发（RAG、Agent、工具调用）已成为软件行业增长最快的新工种。

计算机视觉让机器看懂世界：图像分类、目标检测、分割、三维重建与生成模型，广泛应用于自动驾驶、医疗影像与工业质检。自然语言处理让机器理解与生成语言：从分词、句法分析到对话系统与机器翻译，LLM 时代它正与大模型技术深度合流。

数据科学是面向业务的方法论：数据采集与清洗、探索性分析、统计推断、A/B 实验与因果推断，回答"数据到底在说什么"以及"结论是否可信"。

## 7.3 对口就业与研究方向

就业方向包括 AI 算法工程师（视觉、语音、NLP 等方向）、大模型应用与 Agent 开发、AI Infra（训练框架、推理优化、算力调度）、数据科学家与数据分析师，以及互联网的核心变现引擎——推荐、搜索与广告工程。这一层岗位对学历与论文的要求整体高于其他层，头部岗位竞争激烈，但应用侧（大模型落地）的人才缺口仍然巨大。

研究方向包括机器学习理论（泛化、优化、可解释性）、计算机视觉、自然语言处理、AI 安全（对齐、鲁棒性、越狱防御）与信息检索。多模态理解、具身智能与世界模型是当前最活跃的前沿。

## 7.4 学习建议

避免只会调包：从亲手实现反向传播开始，复现经典论文，参加一次 Kaggle 或天池竞赛，建立"数据—模型—评估"的完整闭环直觉。数学（L1）与工程（L5）两手都要硬——只会推导公式的落不了地，只会调 API 的走不远。
