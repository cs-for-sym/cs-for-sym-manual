# L1 数学地基

## 2.1 层的定位：一切计算的抽象起点

数学是计算机科学的地基，这一点常被初学编程的人忽视——毕竟写出第一段能运行的代码并不需要微积分。但只要走得稍远，数学就会以不可回避的方式出现：算法的正确性需要证明，模型的收敛性需要分析，系统的可靠性需要概率刻画。计算机科学本质上是一门用数学语言描述"计算"这件事的学科，数学地基的深度，直接决定了一个人在本学科能抵达的高度。

这一层的学习成果往往不是一项看得见的技能，而是一种隐形的判断力：看到一个问题，能判断它是否可解、有多难解、用哪类工具刻画最自然。

## 2.2 核心课程与内容

高等数学（微积分）提供连续世界的语言：导数描述变化率，积分描述累积，梯度与极值理论则是一切优化方法的源头——从机器学习中的梯度下降，到工程中的最优设计，本质都是微积分的应用。

线性代数是高维世界的语言：向量、矩阵、特征值刻画了数据的结构与变换。计算机图形学中的每一次旋转缩放、机器学习中每一个参数矩阵、搜索引擎对网页的排序，背后都是线性代数运算。可以说，没有线性代数就没有现代图形学与深度学习。

概率论与数理统计是不确定性世界的语言：条件概率、随机变量、分布与推断，是机器学习、数据科学、排队系统与可靠性分析的共同基础。大模型的"预测下一个词"，在数学上就是一个条件概率估计问题。

离散数学是计算机科学独有的数学：逻辑与集合、图与树、组合计数、递推关系，直接对应着程序的正确性推理、网络与数据结构的建模、算法复杂度的计数分析。如果说前三门课是与物理、工程等学科共享的通用数学，离散数学就是计算机学科的"母语"。

## 2.3 对口就业与研究方向

数学地基几乎不直接对应某个岗位，却是所有方向的隐形门槛——其中人工智能、量化金融与计算机图形学对数学的要求最高，简历筛选与面试中常直接考察线性代数与概率论功底。研究层面，这一层通向理论计算机科学（可计算性与复杂度的数学本质）、量子计算（建立在线性代数与概率之上的全新计算模型）以及科学计算（用数值方法求解连续数学问题）。

## 2.4 学习建议

数学最容易犯的错误是"考完就扔"。正确的姿势是带着计算机问题学数学：学线代时想想它在神经网络里如何被使用，学概率时写写蒙特卡洛模拟，学离散数学时尝试证明一个贪心算法的正确性。让抽象符号始终与具体计算相连，地基才会越打越牢。
