# 结语：纵向扎根，横向生长

七层结构画出了计算机科学与技术的知识等高线，但它不是一道围墙，而是一架梯子。对学习者，我们给出三点建议：其一，地基层的投入永远不算浪费——数学、算法与系统的功底会在十年后依然产生复利；其二，尽早找到自己的"主层"，在一个层次上建立不可替代的深度，再以此为轴心向相邻层扩展；其三，保持纵向打通的自觉——做应用的懂一点系统，做系统的懂一点硬件，做智能的懂一点数学，这种跨界视野正是顶尖工程师与顶尖研究者的共同特征。

学科的边界在不断移动：大模型模糊了 L5 与 L6 的分界，AI 制药让 L7 与生命科学深度交融，存算一体正在重写 L3 与 L4 的接口。但万变不离其宗——分层思维本身，即"在正确的抽象层次上思考问题"，是这张地图送给读者最持久的礼物。
