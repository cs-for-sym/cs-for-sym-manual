下面按国内高校计算机专业的常见课程顺序（大一 → 大四），为每一层配套「轻量级训练项目 + 公开课」。项目都控制在几天到两周内能完成的规模，适合边学边练。

---

## 大一：数学地基（L1）+ 软件与工程层入门（L5）

### L1 数学地基

**训练项目**

- **蒙特卡洛方法估算 π**：用 Python 随机撒点估算圆周率，直观感受概率论（1 天）
- **手写矩阵小库**：用 Python 实现矩阵乘法、旋转矩阵，并用它旋转一张图片（把线性代数"看"出来，3~5 天）
- **函数可视化笔记**：用 matplotlib 画出微积分里的导数、积分、梯度下降过程（配合高数课，随学随画）
- **离散数学小练习**：用代码验证鸽笼原理、实现图的 DFS/BFS 遍历（2~3 天）

**公开课**

- **3Blue1Brown《线性代数的本质》《微积分的本质》**（B 站有中文字幕）——建立几何直觉的最佳入门
- **可汗学院 概率与统计**——免费、节奏平缓，适合配合课堂
- **中国大学 MOOC：浙江大学《概率论与数理统计》**

### L5 软件与工程层（程序设计入门）

**训练项目**

- **命令行小工具**：背单词程序、成绩管理器、简单计算器（C/Python，各 1~2 天）
- **爬虫练手**：抓取学校教务网公告或豆瓣图书 Top250，存成 CSV（2~3 天）
- **TODO 清单网页**：HTML + CSS + 少量 JS，纯前端可运行（3~5 天）

**公开课**

- **中国大学 MOOC：翁恺《C 语言程序设计》（浙江大学）**——国内公认的 C 语言入门首选
- **Harvard CS50**（B 站有中字）——计算机科学导论，视野极佳
- **UC Berkeley CS61A**（Python）——如果想把程序设计学得更"科班"

## 大二：算法与理论（L2）+ 硬件入门（L3）+ 软件进阶（L5）

### L2 算法与理论层

**训练项目**

- **LeetCode 简单题 50 道**：配合数据结构课同步刷，重在说出每题的时间复杂度
- **迷宫生成与求解**：用 DFS 生成迷宫、用 BFS 求最短路并可视化（3~5 天，成就感很强）
- **玩具密码学**：实现凯撒密码、维吉尼亚密码，再写个玩具版 RSA（用大整数，1~2 天）
- **正则表达式迷你引擎**：用 NFA 实现只支持 `a*`、`ab|c` 的小引擎（1 周，体验自动机理论落地）

**公开课**

- **中国大学 MOOC：陈越、何钦铭《数据结构》（浙江大学）**——配 PTA 平台在线刷题
- **MIT 6.006 Introduction to Algorithms**——算法课的标杆，前一半就够本科生用
- **《算法（第 4 版）》配套课程（Princeton, Coursera/B 站）**——Java 实现，讲解细致

### L3 硬件与体系结构层（入门）

**训练项目**

- **Logisim 搭电路**：先搭全加器，再搭一个 4 位 ALU，最后挑战单周期简易 CPU（课程实验级，各 2~3 天）
- **Arduino / 51 单片机点灯进阶**：点亮 LED → 读按键 → 驱动数码管显示学号（套件几十元，1 周）
- **nand2tetris 前半部分**：从与非门一路搭到能跑程序的 Hack 计算机（只做到机器语言层，2 周，强烈推荐）

**公开课**

- **nand2tetris（The Elements of Computing Systems）**——从逻辑门到计算机，神级入门课
- **中国大学 MOOC：华中科技大学《计算机组成原理》**
- **CMU 15-213（CSAPP 配套课）**——如果学校开设了对应课程，提前看前几讲

### L5 软件与工程层（进阶）

**训练项目**

- **个人博客系统**：Flask/Express + SQLite，支持发文、列表、详情页即可（1~2 周）
- **给开源项目提一个 PR**：改文档错别字、修小 bug 都算，重点是学会 Git 协作流程
- **Web 版小游戏**：贪吃蛇 / 2048 / 扫任选一个（3~5 天）

**公开课**

- **CS50 的 Web 编程分支（CS50W）**——前后端一把抓的入门
- **廖雪峰 Python/JavaScript/Git 教程**（免费在线）——工具类知识随用随查

## 大三：系统软件（L4）+ 硬件进阶（L3）+ 智能与数据入门（L6）

### L4 系统软件层

**训练项目**

- **写一个迷你 Shell**：支持管道、重定向、`cd`，几百行 C 代码（1 周，操作系统课的黄金搭档）
- **多线程下载器**：分段并发下载一个文件，体会线程与锁（2~3 天）
- **玩具 HTTP 服务器**：基于 socket 手写，能返回静态网页（2~3 天）
- **迷你数据库**：实现一个支持 `INSERT/SELECT` 的 KV 存储，数据落盘（1~2 周，不必追求 B+ 树）

**公开课**

- **中国大学 MOOC：哈尔滨工业大学《操作系统》（李治军）**——配套实验可上 Linux 0.11
- **CMU 15-445 Database Systems**——数据库内核方向的最佳公开课（做前两个 Project 即可）
- **《 TCP/IP 详解》入门替代：Stanford CS144**——自己动手实现 TCP，硬核但分步清晰

### L3 硬件与体系结构层（进阶）

**训练项目**

- **Verilog 流水灯 / 数字钟**：低成本 FPGA 开发板（百元级）上跑通第一个设计（1 周）
- **RISC-V 模拟器体验**：用 RARS 等模拟器写汇编，单步观察寄存器和内存变化（2~3 天）

**公开课**

- **中国大学 MOOC：《数字逻辑电路》相关课程 + 一生一芯（ysyx）预学习阶段**——想走芯片方向可关注"一生一芯"计划
- **CMU 18-447 Computer Architecture**（看前几章即可）

### L6 智能与数据层（入门）

**训练项目**

- **手写数字识别**：sklearn 或 Keras 跑 MNIST，半天出结果，建立"训练—评估"闭环直觉
- **鸢尾花/泰坦尼克数据分析**：pandas + matplotlib 完成一次完整的数据分析并写结论（2 天）
- **大模型 API 聊天机器人**：调用现成大模型 API，做一个带命令行界面的问答助手（1~2 天）
- **Kaggle 入门赛**：Titanic 或房价预测，提交一次成绩即可

**公开课**

- **吴恩达 Machine Learning Specialization（Coursera/B 站）**——ML 入门经典
- **李宏毅《机器学习》**（B 站，中文）——深度学习入门最友好的中文课
- **CS229 / CS231n**（斯坦福）——数学基础打好后再看

## 大四：智能深入（L6）+ 交叉与应用（L7）

### L6 智能与数据层（深入）

**训练项目**

- **复现一个小模型**：从头训练一个字符级文本生成模型（nanoGPT 精简版思路），观察 loss 下降（1 周）
- **RAG 小应用**：把自己的课堂笔记做成可问答的知识库（调用现成框架，3~5 天）

**公开课**

- **李宏毅《生成式 AI 导论》**（B 站）——大模型时代的入门课
- **斯坦福 CS224n（NLP）**——选看 Transformer 相关几讲

### L7 交叉与应用层

**训练项目**

- **Pygame 小游戏**：飞机大战 / 打砖块，体会渲染循环与碰撞检测（3~5 天）
- **ECharts 数据可视化**：把公开数据集（如城市天气、电影评分）做成一个交互式图表网页（2~3 天）
- **three.js 旋转地球/立方体**：几十行代码体验图形学的魅力（1 天）
- **简易人脸识别签到**：调用现成开源库（如 face_recognition）实现人脸比对（3~5 天）

**公开课**

- **GAMES101《现代计算机图形学入门》（闫令琪，B 站）**——中文图形学第一课，口碑极高
- **UC Berkeley CS188（人工智能导论）**——Pacman 项目贯穿始终，寓教于乐
- **CMU 05-391 HCI 入门讲座 / Coursera 交互设计专项（UCSD）**——HCI 方向选看

## 几点使用建议

1. **项目跟着课程走**：每门课配 1~2 个小项目即可，不要贪多；做完比做大重要得多。
2. **公开课只选一门主线**：同一门课 (如操作系统） 选一套公开课跟到底，频繁换课是学习最大的内耗。
3. **所有项目放 GitHub**：从大二开始把练手项目推上去，毕业时这就是你的简历。
4. **难度随时可降**：任何项目卡住超过预期，就砍掉一半功能——这些项目的目的是建立直觉，不是做出产品。
