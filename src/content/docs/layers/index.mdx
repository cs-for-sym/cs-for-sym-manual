——基于七层模型的课程·就业·研究全景介绍

计算机科学与技术是一门知识跨度极大的学科：向下触及晶体管与布尔代数，向上延伸到金融、生物、设计与人机交互。本导读用七层模型 帮你建立一张学科地图。

## 七层速览

| 层号 | 层名                             | 一句话定位                 |
| ---- | -------------------------------- | -------------------------- |
| L1   | [数学地基](l1-math/)             | 一切计算的抽象起点         |
| L2   | [算法与理论层](l2-algorithm/)    | 计算问题的本质与极限       |
| L3   | [硬件与体系结构层](l3-hardware/) | 计算的物理载体             |
| L4   | [系统软件层](l4-systems/)        | 硬件与应用之间的管理者     |
| L5   | [软件与工程层](l5-software/)     | 把想法变成可靠软件的工程学 |
| L6   | [智能与数据层](l6-ai-data/)      | 从数据中学习的计算范式     |
| L7   | [交叉与应用层](l7-applications/) | 计算与世界、与人的交汇     |

阅读时把握三条主线：

- **支撑线**（下层是上层得以实现的支撑，上层瓶颈常回下层找答案）
- **时间线**（本科学习顺序，自底向上推进）
- **兴趣线**（按兴趣与积累，寻找自己最终的对口方向）
