# 第 3 章 前置知识与入学前准备

上一章我们谈的是时代背景与四年规划的必要性。这一章解决一个更紧迫的问题：距离开学只剩一个暑假，现在还来得及做什么？数学要不要提前学？先给结论：来得及，但方向比时长重要。暑假最有性价比的投入是”一门编程语言 + 一套工具链 + 少量数学直觉”，而不是抢跑大二的硬课。下面分三部分展开：先讲清数学四门课各管什么、预习的边界在哪里，再给一张按优先级排序的可照做清单，最后谈两件比知识更重要的心态准备。

### 3.1 数学地基：四门数学课各管什么

很多新生一听说”计算机要数学好”就焦虑，想整个暑假扑在数学上。先打消这个顾虑：国际通行的 OSSU 计算机自学课程体系明确说明，其核心课程仅假设高中数学水平，零基础新生不会被数学卡住；教育部”101 计划”固化的 12 门核心课中，数学课也只有离散数学一门。数学重要，但它的重要性体现在四年里的持续积累，而不是暑假抢跑。真正需要搞清楚的，是四门数学课各自”管”计算机的哪一块——这决定了你该用什么姿势对待它们。

| 数学课 | 在 CS 中管什么 | 直接支撑的专业课 | 暑假建议姿势 |
| --- | --- | --- | --- |
| 高等数学（微积分） | 连续数学基础：优化方法（如梯度下降）、图形学、信号处理、数值分析 | 机器学习理论、计算机图形学 | 不系统抢跑，建立极限/导数/积分的直观即可 |
| 线性代数 | 向量、矩阵与空间变换，是图形学与深度学习的核心语言 | 机器学习、深度学习、计算机图形学 | 看 3Blue1Brown《线性代数的本质》建立几何直觉，不必刷题 |
| 概率论与数理统计 | 随机性建模：随机算法、数据科学、性能与排队分析 | 机器学习、数据科学、算法分析 | 暑假不碰，开学后认真听课即可 |
| 离散数学 | 逻辑与证明、图论、组合计数、模运算——算法的直接前置 | 数据结构、算法设计与分析、密码学 | 有余力可翻 MIT 6.042 讲义的逻辑与证明章节 |

这张表里有三个值得注意的点。第一，四门课的”紧迫度”并不相同：离散数学与线性代数对 CS 最直接，前者是算法课的直接前置（MIT 的 6.042J《Mathematics for Computer Science》整门课就是围绕逻辑、图、计数、模运算组织的），后者是图形学与深度学习的通用语言（自学路线网站 TeachYourselfCS 明确将线代列为这两个方向的核心）；而微积分和概率论的作用更多体现在大二以后的机器学习和进阶课程里。第二，暑假预习的正确姿势是”建立直觉”而非”系统抢跑”——北大同学维护的 CS 自学指南（csdiy.wiki）强调大一把微积分、线代和写代码放在同等重要位置，但那是开学后的事；暑假里看 3Blue1Brown 的动画视频理解”矩阵是空间变换”这种几何直觉，收益远大于提前刷一本习题册。第三，明确不抢跑的边界：微积分有高中导数基础足够衔接开学，概率论留到课堂，不要试图在暑假自学完一整门数学课——那会挤占编程入门的时间，而且没人答疑的硬啃大概率半途而废。对新生的行动含义很简单：数学这一块，暑假只做”看科普、建直觉”这一件事，每周两三小时封顶。

### 3.2 暑假准备清单（按优先级排序）

明确了数学的边界，暑假的大块时间该投给谁？答案是编程入门和工具链。调研中多份新生学习路线（csdiy、HackWay、TeachYourselfCS）在这一点上高度一致：入学前最有杠杆的事是”写出第一个能跑的程序”和”会用专业工具”。下面这张清单按优先级排序，事项、资源和预计用时都已列明，可以直接照做。

| 优先级 | 事项 | 具体资源与获取方式 | 预计用时 |
| --- | --- | --- | --- |
| 第一优先 | 编程入门（路线 A：Python） | Harvard CS50P、MIT 6.100L（MIT OCW 官网免费开放，Ana Bell 主讲，26 讲+6 个编程作业）或 Stanford CS106A，三选一跟到底 | 40–60 小时 |
| 第一优先 | 编程入门（路线 B：C 语言） | 浙大翁恺《C 语言程序设计》MOOC（中国大学 MOOC 平台免费，含面向准大一的 CAP 先修课）+ 配套教材《C Primer Plus》 | 40–60 小时 |
| 第二优先 | 工具链：编辑器、版本管理、命令行 | 安装 VS Code（官网免费）；注册 GitHub 并学 Git 基础（Learn Git Branching 交互式练习）；Windows 用户安装 WSL2 体验 Linux 命令行；系统学一遍 MIT Missing Semester（官网免费，约 10 小时，有中文版 missing-semester-cn.github.io），Shell/Git/Vim/调试一门覆盖 | 15–20 小时 |
| 第二优先 | Markdown 笔记 | 任选一篇半小时教程，之后所有笔记都用 Markdown 写 | 0.5–1 小时 |
| 第三优先 | 建立兴趣与学科直觉 | Crash Course Computer Science（共 40 集约 8 小时，B 站有中文字幕版）；吴军《浪潮之巅》；3Blue1Brown 线代与微积分系列（B 站有中字版） | 10–15 小时 |

对这张清单做三点解读。其一，两条编程路线不冲突，但也不必都走完：Python 语法简单、反馈快，适合零基础者迅速获得”我能做出东西”的正反馈；C 语言更贴近国内大一课程安排，且是大二组成原理、操作系统等系统课的通用语言——C 学扎实了，后面的硬课会顺很多，这一点下一章的课程地图还会展开。时间充裕可以”先 Python 找感觉、再 C 打地基”，时间紧张则任选一门跟到底，记住 csdiy 社区的共识：“选一门课跟完比囤十门课强”。其二，工具链被排在第二优先，因为它是整个大学生涯的复利投资：Git（版本管理工具，记录代码的每一次修改）和命令行是之后每一门实验课、每一次实习的日常工作环境，而国内培养方案几乎不专门教，MIT Missing Semester 这门”计算机教育中缺失的一课”正是为补这个缺口设计的（其 2026 版还新增了智能体编程一讲）。其三，清单里没写的事同样重要：不要抢跑组成原理、操作系统这类硬课——它们有严格的先修链，没有 C 语言和数字逻辑打底硬啃经典大部头（如《深入理解计算机系统》，俗称 CSAPP）大概率吃灰，社区共识是这类”内功书”至少要到大一下、大二有代码量之后读；不要贪多门语言；最重要的一条——不要只看视频不动手，入门期的时间权重应是看课不低于动手练习，书只当速查——但练习不能省，只看不写是入门期最大的坑。

### 3.3 开学前的心理建设

清单之外，还有两件事比任何一门课都更能决定你前两年的体验。

第一件事，把编程理解为一门手艺，而不是一门知识。知识可以靠考前背诵获得，手艺只能靠练。衡量入门进度的标准不是”看完了多少讲”，而是”做出了什么东西”——哪怕只是一个猜数字小游戏、一个自动整理文件的脚本。同时要提前接受一个事实：调试两小时、最后只改了一行代码，是这个行业的日常，不是你的耻辱。新手最大的挫败感来源就是以为”高手不卡壳”，实际上所有人都会卡，区别只在排查问题的熟练度。把目标从”看懂”切换到”做出来”，你会更耐受这种卡顿。

第二件事，学会提问与搜索。计算机是少数官方文档和一手资料完全免费公开、且全球最聪明的人乐于在网上回答好问题的领域，但前提是你问得对。csdiy 将《提问的智慧》（How To Ask Questions The Smart Way，GitHub 上有完整中文译本）列为新生应读的”第一项工具”，读它的用时不超过两小时，回报贯穿整个职业生涯。具体来说：遇到问题先读官方文档和报错信息，再用精确的关键词（最好是英文）搜索，最后带着”我试过什么、卡在哪一步”去提问。善用英文资料这一点也请从现在就建立习惯——几乎所有一手技术资料的母语都是英文，这也是大一尽早过四六级的现实原因之一。会提问的人，等于随身带着一位无限耐心的助教，这项能力开学第一天就派得上用场。
